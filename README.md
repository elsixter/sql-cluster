# SQL y Administración de PostgreSQL

Repositorio de práctica para desarrollar habilidades en SQL y administración de bases de datos PostgreSQL, con énfasis en entornos Linux.

## Objetivo

Aprender mediante ejercicios prácticos a consultar y manipular datos, administrar clústeres PostgreSQL, configurar el servidor y comprender los procesos básicos de operación y mantenimiento.

## Temas trabajados

### SQL
- Consultas con `SELECT`, filtros y operadores lógicos.
- Subconsultas, agrupaciones y funciones de agregación.
- Operaciones CRUD: `INSERT`, `UPDATE` y `DELETE`.
- Roles, usuarios y permisos.

### Administración de PostgreSQL en Linux
- Creación manual de un clúster con `initdb`.
- Inicio, detención y consulta del estado con `pg_ctl`.
- Configuración del servidor mediante `postgresql.conf`.
- Puertos y parámetros de configuración.
- Exploración de los archivos de autenticación y acceso.

## Documentación

Los apuntes y procedimientos se encuentran en `docs/postgresql/`:

- `manual-postgresql-cluster-linux.md` — creación del clúster manual.
- `cluster-manual-linux.md` — ciclo de vida del clúster.
- `configuracion-postgresql.md` — parámetros y configuración del servidor.

*Los nombres de los archivos anteriores son referencias; verifica que coincidan con los nombres reales de tu directorio.*

## Entorno de práctica

- Sistema operativo: Linux (Ubuntu).
- Sistema gestor de bases de datos: PostgreSQL 16.
- Control de versiones: Git y GitHub.

## Enfoque

Este repositorio documenta el aprendizaje progresivo mediante ejercicios, comandos, pruebas y documentación técnica. Los cambios importantes se registran mediante commits de Git.
